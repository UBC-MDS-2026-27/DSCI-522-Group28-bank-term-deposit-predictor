# Code of Conduct
## Our Commitment
We welcome people with all backgrounds, identities, and level of experience around the world to access. Every member contributing, viewing in this project deserves respect. 

## Expected Behavior
Be respect, responsible for the GitHub issues, pull requests, reviews, and all other project discussions. Create an open space for everyone who is trying to ask questions, credit contributions and sources, and show respect to others' time and contributions.
Be authentic, honest, and treat the confidential files carefully.

## Unacceptable Behavior
Harassment (including any types: oral, gestures, languages, and etc.), discrimination, intimidation, sexual attention or language.
Publishing others' work or private information without permission.
